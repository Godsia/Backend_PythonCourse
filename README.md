# Django API Project

## Установка зависимостей
1. Надо установить зависимости:
    ```bash
    pip install -r requirements.txt
    ```

2. Потом применить миграции базы данных:
    ```bash
    python manage.py migrate
    ```

3. В конце просто зхапустить сервак:
    ```bash
    python manage.py runserver
    ```
